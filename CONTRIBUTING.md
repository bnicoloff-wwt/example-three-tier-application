# Contributing

## Run the App Locally

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the application: `npm start`
4. The app will be available at `http://localhost:3000`

## Run the Tests

Execute the test suite with:

```bash
npm test
```

## Open a Pull Request

1. Create a new branch for your changes: `git checkout -b feature/your-feature-name`
2. Make your changes and commit them: `git commit -m "Description of changes"`
3. Push to your branch: `git push origin feature/your-feature-name`
4. Go to the repository and click "New Pull Request"
5. Fill in the PR description and submit
